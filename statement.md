# Project Statement

## Problem Statement

Many word games need a phone or a website, and they often have ads or only give you one fixed way to play. Beginners who are learning Python also need small, fun projects where they can practice real programming ideas instead of only reading theory.

This project solves both problems. It is a simple word guessing game that runs in the terminal, with no internet or account needed once it is set up. You can play it for fun, and the code is easy to read and learn from.

## Scope of the Project

What the project covers:

- A word guessing game that runs in the terminal
- Two ways to play: a completely random word, or a word from a category you choose
- Three difficulty levels in random mode: easy, medium and hard
- Colored feedback after every guess so the player knows how close they are
- A limited number of chances and a hint if the player is running low
- Checking that every guess is a real word of the right length
- An option to play again after a game ends

What the project does not cover:

- No graphics, sound or a window. It only works in the terminal
- No online play, scores or leaderboards
- No saving of progress after the game is closed
- No automated tests. It is checked by playing the game

## Target Users

- Anyone who enjoys word games like Wordle and wants a quick game to play
- Students and beginners learning Python who want a small project to read, run and change
- Friends or classmates who want a simple game to play together on one computer, by taking turns

## High-Level Features

- Random word mode and category mode
- Ten categories such as Movies, Animals, Sports and Science
- Easy, medium and hard levels based on word length
- Green, yellow and red letters to show right, misplaced and wrong letters
- Messages after each guess that tell the player how close they are
- List of all previous guesses shown after every turn
- One hint per game that reveals a letter the player has not found yet
- Guess checking so invalid words do not use up a chance
- Play again option at the end of each game
